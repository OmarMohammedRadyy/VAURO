# اقربلك (Eqreblk)

منصة متعددة الأدوار تربط العملاء وأصحاب المتاجر والسائقين والمديرين مع تجربة اقتراحات ذكية لأقرب المتاجر.

## المكونات

- **apps/api**: واجهة خلفية مبنية بـ NestJS (تخزين داخل الذاكرة لأغراض التطوير).
- **apps/web**: واجهة أمامية مبنية بـ React + Vite مع Ant Design.

## البدء

```bash
npm install
npm run build --workspaces
npm run start --workspace apps/api
npm run dev --workspace apps/web
```

يعمل الـ API افتراضياً على المنفذ `4000` بينما الواجهة تعمل على `5173` مع بروكسي `/api`.

## بنية الـ API (مختصر)

- `POST /users` تسجيل حساب جديد حسب الدور.
- `POST /users/login` تسجيل الدخول (يوفر رمز تجريبي).
- `GET /stores/nearby` اقتراحات أقرب المتاجر اعتماداً على الإحداثيات.
- `GET /catalog/products` و `POST /catalog/products` لإدارة المنتجات.
- `POST /orders` إنشاء طلب و `PATCH /orders/:id/status` لتحديث الحالة.

> النظام يستخدم ذاكرة مؤقتة داخلية ويمكن استبداله بقاعدة بيانات فعلية لاحقاً.

## الواجهة الأمامية

- تدفق تسجيل/تسجيل دخول متكيف مع الأدوار.
- لوحات خاصة لكل دور: عميل، صاحب متجر، سائق، مدير.
- مكونات تصميم RTL ولغة عربية مع ألوان متناسقة.

## ملاحظات التطوير

- الشفرة مصممة لتكون أساساً أولياً يمكن توسعته لدمج قاعدة بيانات SQL Server وعمليات مصادقة JWT حقيقية.
- يدعم الهيكل إضافة وحدات جديدة بسهولة في الواجهة والخلفية.
